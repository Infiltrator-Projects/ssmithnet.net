Four places to start

Selected engineering work.

These are entry points into the larger codebase, not a ranking of completed products. Each has its own qualification and development history.

01 / Storage

InfiltratorFS

My clean-sheet filesystem: generation-based copy-on-write, checkpoints, snapshots, and integrity checks. The interesting question is what data and metadata survive an interrupted operation.

Architecture and limits ↗Source ↗
02 / Foundations

InfiltratorOS

A developing operating environment with independent Boot, Kernel, Files, and filesystem components. I am testing the contracts between them rather than treating one passing subsystem as a finished OS.

How the layers fit ↗Source ↗
03 / Native applications

System Monitor

A native tool for inspecting the running machine through operating-system interfaces. Its implementation and tests belong in the same conversation as the results shown to users.

Application approach ↗Source ↗
04 / Vehicle diagnostics

MBLink

Mercedes-Benz diagnostics built on the shared Link engine, informed by work with my own C207 E 250 CDI. Identification, capture, and interpretation are different responsibilities.
