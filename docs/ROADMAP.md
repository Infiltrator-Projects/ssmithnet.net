# Roadmap

This roadmap describes direction rather than dates. Current support is defined by the tested source.

## Current foundation

- maintain deterministic generation of Home, Workbench, Garage and Archive pages
- keep committed mirrors byte-aligned with generator output
- publish only the finished static artifact

## Near-term priorities

- keep content and Workbench/Garage/Archive structures current without duplicating layout logic
- continue consolidating genuinely neutral web mechanics in Common
- strengthen validation whenever generator responsibilities grow

## Longer-term direction

- evolve presentation conservatively while retaining static deployability and deterministic generation
- add new sections only through reusable generator structure rather than hand-maintained page copies

## Admission rule

New work needs clear ownership and a credible validation path. Reference material or an attractive idea is not automatically a product commitment.

## Completion rule

Implementation, tests, user-visible behaviour and maintained documentation must agree before an item is considered complete.
